# Concert Notificatorfier
Goal: A webapp for tracking concerts/events from creators of your choosing so that you get notified when there is one upcoming
## MVP
-Parsing a stored list creators<br>-Pulling data for creators from Ticketmaster API<br>-Tracking upcoming events via a timed check (cronjob?)
### Future Plans
-API for adding new creators to the creator list<br>-Sending notifications through OS<br>-Integration with calendars
### Tech stack
Backend: TypeScript with Node + Express<br>Frontend: html+css (optionally React)
